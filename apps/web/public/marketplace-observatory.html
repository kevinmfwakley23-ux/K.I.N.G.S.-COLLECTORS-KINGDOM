Method

What this snapshot means

The server walks the current Marketplace through the same bounded keyset pagination used by buyers. Every included offer has to remain active, backed by the seller's current Royal Vault quantity, and pass its published-representation SHA-256 integrity check.

For an even number of offers, the Observatory reports both middle-rank asking prices rather than manufacturing an average half-cent value. If the verified scan would exceed 10,000 active offers, the endpoint fails closed instead of publishing partial statistics as complete.
